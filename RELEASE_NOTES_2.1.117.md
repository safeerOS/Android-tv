# Safeer Browser for Android TV 2.1.117 · Safeer OS 0.4.0 · Safeer OS Tablet 0.3.0

**Safeer OS gets a new look, and Safeer Link becomes part of the system.**

- **New home screen for Safeer OS.** A side menu (Home, Apps, Screen, Files, Devices, Settings), three large cards for the web browser, the computer screen and computer programs, and your web apps and TV apps right below them. The new default wallpaper is a photo of a mountain lake; the cards sit directly on it instead of on dark panels.
- **Clearer app icons.** Icons of TV apps are taken in the highest resolution the app ships, so they are sharp on a 1080p TV. Wide logos (such as Netflix) get a rounded backing like on the Android TV home screen instead of floating on the wallpaper.
- **Apps and Files are easier to browse.** In All apps, three full rows fit on the screen. Files has a search box: type part of a folder name and the list shows only the matches (letters with or without diacritics both work). Computers are shown by their own name, without the program name repeated.
- **Safeer Link is part of Safeer OS.** Opened from Devices or the home screen, Safeer Link now sits on the Safeer OS wallpaper and closing it returns you to where you were in Safeer OS, not to the browser. When Safeer Link is already running, only the "Turn off" button is shown and it is no longer the first thing the remote selects, so one accidental OK can no longer switch Safeer Link off for every device.
- **New browser home page.** Safeer Browser on the TV has a new start page with your websites as large cards.
- **Safeer OS Tablet: the same design for touch**, in landscape and portrait, with the option to turn on Safeer Link and to reconnect.
