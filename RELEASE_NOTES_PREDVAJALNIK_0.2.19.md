# Safeer Predvajalnik 0.2.19

- Nastavitve → Obvestila (stanje in pot do sistemskih nastavitev); pošiljatelj izve, ko obvestilo na cilju ni vidno (televizor v ozadju, izklopljena obvestila).

English: Settings → Notifications (state and a shortcut to the system page); the sender is told when a notification is not visible on the target.
