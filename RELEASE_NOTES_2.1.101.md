# Safeer Browser for Android TV 2.1.101

**Safeer Shield answers only its own questions, and a more careful description of what it does.**

- **Shield: replies are now verified.** Every query the Shield forwards gets its own random transaction ID, and an answer is accepted only when it comes from the server that was asked, from port 53, and carries the same question. Before, two apps that happened to pick the same DNS ID could get each other's answer, and anything on the network that guessed the ID could have slipped an answer in.
- Shield: fixed a bug where a short reply shrank the receive buffer, so the next, longer reply could be cut off.
- **A more honest description of the Shield.** The list and the decision stay on the television, and nothing is sent to us — but allowed queries do go on to your network's DNS resolver (Cloudflare or Quad9 only if the network offers no resolver of its own), and apps that use their own DNS-over-HTTPS bypass this filter. The previous wording ("no traffic is routed anywhere") was too broad and has been corrected here and on safeer.si.
- **Web apps: limits while downloading.** A site's icon is now read with a size cap and its dimensions are checked before decoding, instead of loading the whole file and decoding it at full size; the web app manifest is capped too. On a television with little memory, an oversized icon could have cost much more memory than it was worth.
- Missing English strings added, and the translation check now ignores strings marked as not translatable.
- Every push now runs the Shield's own tests (domain set, DNS packets, reply matching) on GitHub, next to the other checks.

Slovensko: **Ščit odgovarja samo na svoja vprašanja.** Vsaka poizvedba, ki gre naprej, dobi svoj naključni ID, odgovor pa sprejmemo le, če pride s strežnika, ki smo ga vprašali, z vrat 53 in z istim vprašanjem; doslej sta si dve aplikaciji z istim ID-jem lahko zamenjali odgovor, kdorkoli v omrežju pa bi z ugibanjem ID-ja lahko podtaknil svojega. Popravljeno je tudi, da kratek odgovor ni več skrajšal naslednjega. **Opis Ščita je zdaj natančen:** seznam in odločitev sta na televizorju in nam ne pošljemo ničesar, dovoljene poizvedbe pa gredo naprej razreševalcu tvojega omrežja (Cloudflare ali Quad9 samo, če omrežje svojega ne ponudi), aplikacije z lastnim DNS-over-HTTPS pa tega filtra ne uporabljajo; prejšnje besedilo (»promet ne gre nikamor«) je bilo preširoko in je popravljeno tudi na safeer.si. **Spletne aplikacije:** ikona strani se zdaj bere z omejitvijo in se pred dekodiranjem preveri njena velikost, omejen je tudi manifest — na televizorju z malo pomnilnika je prevelika ikona prej stala veliko več, kot je bila vredna. Dodani so manjkajoči angleški nizi, preverba prevodov pa ne zahteva več prevoda nizov, ki se ne prevajajo. Ob vsakem potisku se na GitHubu poženejo tudi testi Ščita.
