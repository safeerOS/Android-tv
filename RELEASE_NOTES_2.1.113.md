# Safeer Browser for Android TV 2.1.113 · Safeer OS 0.3.1

**Small steps that make Safeer OS 0.3 feel finished.**

- **Programs in the Continue row show their own icon.** A program from the computer used to appear there as a generic computer; now it has the icon the computer sends with the list of programs, so six cards no longer look the same.
- **A program opened from the home screen goes into Continue.** Opening a program from its home-screen card now puts it at the front of the Continue row, just like opening it from the list — so you can find it again and close it there (✕).
- **"Computer screen" appears in Continue only for the whole desktop.** Before, every program opened from the TV also pushed a "Computer screen" card to the front, and that card opened the desktop, not the program.
- Safeer Browser for Android TV: when a new device (for example Safeer OS Tablet) gives up joining, the code on the TV now disappears right away instead of staying until it expires.
- Safeer OS Tablet (beta) 0.2.1: the status at the top says "Not connected to a TV yet" until the tablet has joined the TV, instead of "Connected" to the tablet itself; cancelling the code entry also removes the code from the TV.
