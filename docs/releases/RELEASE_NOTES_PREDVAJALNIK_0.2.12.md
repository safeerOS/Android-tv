# Safeer Predvajalnik 0.2.12

- Dodatki Stremio kot v Stremiu: Cinemeta vedno zraven, *Pokaži vse* in *Naloži več* za kataloge, tokovi z zahtevanimi glavami (`proxyHeaders`); računalnik s Safeer Controlom je lahko pomočnik pri sprotnem pretvarjanju.

English: Stremio add-ons like in Stremio – Cinemeta always present, *Show all* and *Load more* for catalogues, streams with required request headers (`proxyHeaders`); a computer with Safeer Control can help with live transcoding.
