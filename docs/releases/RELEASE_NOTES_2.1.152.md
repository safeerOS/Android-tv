# Safeer OS 0.5.28 (TV, tablica, telefon) · Safeer Browser za Android TV 2.1.152

- **Posodobitve z enim dotikom:** Safeer OS sam preveri safeer.si (vsakih nekaj ur, tiho) in ob novi različici pokaže majhno pasico »Nova različica Safeer OS … je na voljo« z gumboma Namesti / Pozneje. Namesti prenese APK (preverjena vsota SHA-256) in ga preda sistemskemu nameščanju – nič se ne namesti brez tebe. V Nastavitvah je vrstica **Posodobitve** (»Najnovejša (0.5.28)« ali »Na voljo …«), ki preveri takoj. Ob prvi posodobitvi Android enkrat vpraša, ali Safeer OS sme nameščati aplikacije.
- Enako velja za Safeer Browser za Android TV in Safeer Predvajalnik.

English: one-tap updates – Safeer OS checks safeer.si itself, shows a quiet banner with Install / Later, downloads the APK (SHA-256 verified) and hands it to the system installer; a Settings → Updates row checks right away. Same for the TV browser and the player.
