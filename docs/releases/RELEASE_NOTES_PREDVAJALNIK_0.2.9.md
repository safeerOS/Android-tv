# Safeer Predvajalnik 0.2.9

- **Skupni prostor:** ko je Predvajalnik v Safeer Linku edina Safeer aplikacija na napravi, lahko shrani datoteko računalnika, ki mu zmanjkuje prostora (mapa *Prenosi › Safeer Shramba*, preverjena vsebina). Če je na napravi Safeer OS, to opravi Safeer OS.

English: Shared space – when the player is the only Safeer app on the device, it can store a file for a computer that is running low on space (*Downloads › Safeer Shramba*, verified content). If Safeer OS is on the device, Safeer OS does it.
