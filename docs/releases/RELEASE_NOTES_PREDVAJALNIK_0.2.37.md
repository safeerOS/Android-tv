# Safeer Predvajalnik 0.2.37

- **Vdelane spletne strani niso več odmaknjene od roba dvakrat (Android 15 in novejši).** Predvajalnik vsebino odmakne od vrstice stanja in navigacijske vrstice; isti odmik je doslej dobila še spletna stran v njem in ga upoštevala po svoje. Popravek je v kodi, ki jo ima Predvajalnik skupno s Safeer OS, in je bil izmerjen v brskalniku Safeer OS (Android 16: prej 30 in 48 točk, zdaj 0). Drugih sprememb ni.

English: embedded web pages are no longer inset from the screen edges twice on Android 15 and newer – the player already keeps content clear of the status and navigation bars, and the same inset also reached the web page inside it. The fix is in code the player shares with Safeer OS and was measured in the Safeer OS browser (Android 16: 30 and 48 px before, 0 now). No other changes.
