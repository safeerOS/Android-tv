# Safeer Predvajalnik 0.2.1 (Android)

Popravek zvoka pri internetnem radiu (isti predvajalnik kot Medijski center v Safeer OS 0.5.7).

**Popravljeno**
- Internetni radio (tokovi z naslovi skladb – Icecast/Shoutcast, npr. Radio 1, Rock Radio) ne praska več 1–2× na sekundo: predvajalnik zdaj pravilno odstrani bloke metapodatkov, ki jih strežnik vrine v tok.
- Pod imenom postaje se izpiše skladba, ki trenutno igra.

**Fixed (English)**
- Internet radio streams with ICY metadata (Icecast/Shoutcast) no longer crackle once or twice a second – the metadata blocks are now stripped correctly.
- The currently playing song is shown under the station name.
