# Safeer Browser for Android TV 2.1.114 · Safeer OS 0.3.2

**Safer icons and more automatic checks.**

- **Program icons are decoded safely.** An icon that comes from the computer (the list of programs, the Continue row, programs on the home screen) is first measured and then decoded at most 512 pixels on its longer side; an image with absurd dimensions is not decoded at all. Before, a small file with huge dimensions could use hundreds of megabytes of the TV's memory. Icons of programs pinned to the home screen are stored only up to 512 KB.
- **More checks run on every change.** The automatic checks on GitHub now also test the Hub and pairing (including cancelling a pairing: only the device that started it can cancel it, and not after it was confirmed), Hub streams, signed threat lists, threat rules, domains, ad blocking, and the rules of Safeer OS (icon sizes, the Continue row and its icons, the "Computer screen" card). Before, most of these ran only on our computer. Android Lint now stops the automatic build on any new error; existing warnings are listed in a baseline and will be fixed step by step.
- Fixed a test script for Hub streams that no longer compiled.

Slovensko: **Ikone programov se dekodirajo varno.** Ikona, ki pride z računalnika (seznam programov, vrstica Nadaljuj, programi na domačem zaslonu), se najprej izmeri in nato dekodira na največ 512 pik po daljši stranici; slike z nesmiselnimi merami ne dekodiramo. Prej je lahko majhna datoteka z ogromnimi merami porabila stotine MB pomnilnika televizorja. Ikone pripetih programov hranimo samo do 512 KB. **Več preverjanj ob vsaki spremembi:** samodejne preverbe na GitHubu zdaj preizkusijo tudi Hub in seznanjanje (tudi preklic: prekliče ga lahko samo naprava, ki ga je začela, in ne po potrditvi), tokove, podpisane sezname in pravila groženj, domene, blokiranje oglasov ter pravila Safeer OS (mere ikon, vrstica Nadaljuj in njene ikone, kartica »Zaslon računalnika«). Android Lint zdaj ustavi samodejno gradnjo ob vsaki novi napaki; obstoječa opozorila so zapisana posebej in jih odpravljamo postopoma. Popravljen preizkus tokov, ki se ni več prevedel.
