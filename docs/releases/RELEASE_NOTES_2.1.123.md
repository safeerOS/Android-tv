# Safeer Browser for Android TV 2.1.123 · Safeer OS 0.4.6 · Safeer OS Tablet 0.3.6

**Safeer Media: your sources work like favourite apps.**

- The dashboard shows only the sources you pin – by default this device, devices in Safeer Link and radio stations. Everything else stays in *My sources*.
- *My sources* shows all sources in a grid. Hold OK on a source to put it on the dashboard or take it off – straight away, a star shows which ones are pinned. A source you added yourself can also be deleted there.
- Hold OK on a source on the dashboard: *Move* (left/right, OK to finish) or *Take off the dashboard* – the same as favourite apps on the home screen. On the tablet: *Move left* / *Move right*.
- Nothing is cut off any more: sources that do not fit on the screen are under the last card, *All sources*.
- Cards without a picture show a moderately sized icon instead of one across the whole card.

Slovensko: **Safeer Media – tvoji viri delujejo kot priljubljene aplikacije.** Na plošči so samo viri, ki jih pripneš (privzeto ta naprava, naprave v Safeer Linku in radijske postaje). V *Mojih virih* so vsi viri v mreži; zadržan OK vir da na ploščo ali ga umakne (zvezdica pove, kateri so pripeti), dodan vir lahko tam tudi izbrišeš. Zadržan OK na plošči: *Premakni* (levo/desno, OK konča) ali *Umakni s plošče* – enako kot priljubljene aplikacije. Nič ni več odrezano: kar ne gre na zaslon, je pod kartico *Vsi viri*.
