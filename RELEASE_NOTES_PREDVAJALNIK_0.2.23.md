# Safeer Predvajalnik 0.2.23

- **Filmi in Serije kot mreža plakatov** z izbiro zvrsti in razvrstitvijo, čez vse tvoje vire; naslednje strani se naložijo same.
- **Film se začne takoj** z najboljšim tokom za tvojo napravo, brez seznama virov; če ne steče, Predvajalnik sam poskusi naslednjega. Ročna izbira: dolg pritisk → »Izberi vir«.
- Posodobitev se po dovoljenju za nameščanje nadaljuje sama; sporočila o posodobitvi govorijo o Safeer Predvajalniku.

English: Movies and Series as a poster grid with genre and sort filters; a title starts right away with the best stream for your device (manual choice via long-press → "Choose source"); the update continues by itself after the install permission.
