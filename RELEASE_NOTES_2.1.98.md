# Safeer Browser for Android TV 2.1.98

**Remote control from your phone or computer, refined — and Safeer Control on the computer without a code.**

- The Menu key on the remote opens the TV menu and the remote's keys then move inside it (before, they moved the page under the menu); Back and Menu close it.
- The remote's header says which device is the Safeer Link hub and whose apps are listed; app entries without a real name are gone.
- Safeer Link: the home page is no longer offered for sending; a refused action does not colour the window yellow; a device whose pairing this TV no longer knows is told to pair again.
- Hub: a sibling device on the same computer (Safeer Control next to Safeer Browser) joins without a new code; the device list carries each device's address so the remote can name the hub.
