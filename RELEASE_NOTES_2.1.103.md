# Safeer Browser for Android TV 2.1.103 · Safeer OS 0.2.3

**Safeer OS is now an app of its own. Android sees two apps — Safeer Browser and Safeer OS — and they still work as one.**

- **Two apps, one key, one set of settings each.** Safeer OS installs as `si.safeer.os`, Safeer Browser stays `si.safeer.tv`. Each has its own name, icon, entry in the launcher, its own settings and its own uninstall. The browser no longer carries the Safeer OS screens, and Safeer OS no longer adds a browser entry. Only Safeer OS can take over the Home key, and only when you switch that on yourself.
- **No second connection, no second filter.** With the browser installed, Safeer OS joins Safeer Link through it (a signature-protected bridge on the TV), so your television is still one device in Link, and the Shield stays a single DNS filter that Safeer OS shows and switches through the browser. Without the browser, Safeer OS does both on its own — the code is in both apps.
- **Your web apps move with you.** The first time Safeer OS starts, it takes over the web apps you had added in the browser, so the home screen is not empty. Adding a page from the browser menu still lands on the Safeer OS home screen, through a provider only apps signed with the same key can reach.
- **The web opens in the browser and comes back.** The Web card opens Safeer Browser; leaving the browser returns you to Safeer OS instead of dropping you on the Android home screen. The browser's own Home button still goes to the browser's home page. If you do want plain Android, Safeer OS settings now have **Exit to Android**, and the Home-screen switch above it is the permanent choice.
- **Fits the screen.** Card widths are computed from the width of your screen, so a card is never cut in half at the edge and no text is clipped. The rows are calmer too: no borders until a card is focused, then a mint outline and a soft glow; bigger icons for web apps; devices as compact status cards; and the Shield now says "Protection is on · 95 blocked today" instead of a full line of status.
- **A web app from any address.** In Add you can now type an address with the TV keyboard, not only pick a page you already have.

Slovensko: **Safeer OS je zdaj svoja aplikacija.** Namesti se kot `si.safeer.os`, Safeer Browser ostaja `si.safeer.tv`; Android ju vidi kot dve aplikaciji — vsaka s svojim imenom, ikono, vnosom v zaganjalniku, svojimi nastavitvami in svojo odstranitvijo. Brskalnik nima več zaslonov Safeer OS, Safeer OS pa ne vnosa brskalnika; tipko Domov lahko prevzame samo Safeer OS in samo, če to sam vklopiš. **Nove povezave in drugega filtra ni:** ko je brskalnik nameščen, Safeer OS vstopi v Safeer Link prek njega (most istega podpisa na televizorju), zato je televizor v Linku še vedno ena naprava, Ščit pa en sam filter, ki ga Safeer OS kaže in preklaplja prek brskalnika; brez brskalnika oboje opravi sam. **Spletne aplikacije gredo s tabo:** ob prvem zagonu jih Safeer OS prevzame iz brskalnika, dodajanje strani iz menija brskalnika pa še vedno pristane na domačem zaslonu Safeer OS. **Splet se odpre v brskalniku in se vrne:** kartica Splet odpre Safeer Browser, izhod iz brskalnika pa te vrne v Safeer OS in ne vrže na zaslon Androida; gumb Domov v brskalniku ostaja gumb brskalnika. Če hočeš navaden Android, je v nastavitvah Safeer OS nova vrstica **Izhod v Android**, vrstica Domači zaslon televizorja nad njo pa je trajna izbira. **Prilagojeno zaslonu:** širine kartic se izračunajo iz širine zaslona, zato ob robu ni več polovične kartice in besedilo ni odrezano; kartice so mirne, dokler jih ne izbereš, spletne aplikacije imajo večje ikone, naprave so statusne kartice, Ščit pa pove "Zaščita je vključena · 95 blokiranih danes". **Spletno aplikacijo lahko dodaš z lastnim naslovom,** vtipkanim s tipkovnico televizorja.
