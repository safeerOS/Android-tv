# Safeer Predvajalnik 0.2.18

- Pošlji na napravo / Nadaljuj z druge naprave tudi z računalnikom (Linux, Windows); pošiljatelj izve, če so na cilju obvestila izklopljena (tam odpri Safeer OS in potrdi s Sprejmi).

English: Send to device / Continue from another device now also with the computer (Linux, Windows); the sender is told when notifications are off on the target (open Safeer OS there and press Accept).
