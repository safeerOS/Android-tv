# Safeer OS 0.5.9 (TV, tablica, telefon) · Safeer Browser za Android TV 2.1.133

- **Povezovanje s 6-mestno kodo zdaj vedno uspe:** ko na napravi izbereš *Vpiši kodo z druge naprave*, Safeer kodo pošlje prav tisti napravi, ki jo kaže (računalnik, televizor, tablica ali telefon). Prej je šla prvi napravi, ki se je v omrežju oglasila – odkar ima Safeer Link središče na vsaki napravi, je bila to pogosto napačna in koda »ni delovala«.
- **Vsaka naprava pove, ali kaže kodo:** televizor, tablica in telefon zdaj drugim napravam sporočijo, ali imajo odprto okno *Poveži naprave* (koda sama nikoli ne gre po omrežju).

English: Pairing with the 6-digit code now always reaches the right device – *Enter a code from another device* sends the code to the device that is actually showing it (computer, TV, tablet or phone) instead of whichever Safeer device answered first on the network. Each device now tells others whether it is showing a pairing code; the code itself never travels over the network. No browser changes in 2.1.133.
