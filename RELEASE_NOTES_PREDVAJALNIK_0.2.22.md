# Safeer Predvajalnik 0.2.22

- Posodobitev se po dovoljenju za nameščanje nadaljuje sama in se odpre naravnost v sistemskem namestitelju (brez izbirnika aplikacij).
- Sporočila o posodobitvi govorijo o Safeer Predvajalniku (prej »Safeer OS«).

English: the update continues by itself after the install permission is granted and opens the system installer directly; update messages now name Safeer Player.
